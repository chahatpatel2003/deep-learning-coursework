# Deep Learning Coursework

A structured collection of Jupyter notebooks completed for deep-learning coursework at California State University, Fresno.

## Topics Covered

- Linear models and loss functions
- Shallow and deep neural networks
- ReLU and other activation functions
- Regression and classification
- Maximum likelihood and probability distributions
- Gradient descent, stochastic gradient descent, momentum, and Adam
- Forward propagation and backpropagation
- Training, regularization, and data augmentation
- Convolution, pooling, and convolutional neural networks
- Self-attention, multi-head attention, tokenization, and transformer decoding

## Running the Notebooks

```bash
python3 -m pip install -r requirements.txt
jupyter notebook
```

Some notebooks were originally developed in Google Colab and may install additional packages inside individual notebook cells.
